# 📚 PAS UEM 2026 — Guia de Conteúdos

Site interativo para consultar os conteúdos do **Processo de Avaliação Seriada (PAS) da Universidade Estadual de Maringá (UEM)**, organizado por etapa e disciplina.

O projeto reúne os principais conteúdos de estudo do PAS UEM 2026 em uma interface simples, organizada e responsiva, facilitando a consulta e o planejamento dos estudos.

## 🚀 Funcionalidades

- 📖 **Conteúdos por etapa:** acesso aos conteúdos da Etapa 1 (1º ano), Etapa 2 (2º ano) e Etapa 3 (3º ano).
- 📝 **15 disciplinas:** Redação, Português, Literatura, Espanhol, Francês, Inglês, Arte, Educação Física, Filosofia, Geografia, História, Sociologia, Matemática, Biologia, Física e Química.
- 🔄 **Navegação interativa:** alterne entre as etapas para visualizar os conteúdos correspondentes.
- 📱 **Design responsivo:** interface adaptável a diferentes tamanhos de tela.
- 🌙 **Tema escuro:** suporte à preferência de tema do dispositivo.
- ⚡ **Leve e rápido:** desenvolvido com HTML, CSS e JavaScript puro, sem dependências externas.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura da página.
- **CSS3:** estilização, layout responsivo e temas.
- **JavaScript:** navegação entre etapas e renderização dinâmica dos conteúdos.

## 📂 Estrutura do projeto

```text
pas-uem-2026/
├── index.html
└── README.md
```

O arquivo `index.html` contém a estrutura, os estilos e a lógica de funcionamento do site.

## 📅 Sobre o projeto

O projeto foi criado para facilitar a visualização e a organização dos conteúdos de estudo do PAS UEM 2026, reunindo diferentes disciplinas em uma única página.

**Importante:** os conteúdos apresentados devem ser conferidos com os documentos e editais oficiais da UEM. Este projeto é independente e não possui vínculo oficial com a universidade.
